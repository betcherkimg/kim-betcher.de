4. Datenerfassung auf dieser Website

Lokale Inhalte und Projektbeispiele

Beim ersten Aufruf lädt die Startseite ausschließlich lokal bereitgestellte Schriftarten, Bilder und Skripte. Die Website selbst setzt keine Analyse- oder Marketing-Cookies. Externe Videoinhalte werden erst nach Ihrem Klick geladen.

Die Projektgalerie zeigt bereitgestellte Bilder und Grafiken. Beim Vergrößern werden diese vom Server dieser Website geladen. Dabei werden keine Haushaltsprofile oder App-Daten abgefragt.

Wenn Sie die Schaltfläche zum Kopieren der Kontaktadresse verwenden, schreibt Ihr Browser ausschließlich diese E-Mail-Adresse in Ihre Zwischenablage. Vorhandene Inhalte der Zwischenablage werden nicht gelesen.

3D-Spielfiguren

Die Spielfiguren auf der Startseite und die dafür nötigen Programmbibliotheken werden vom Server dieser Website geladen. Es wird dabei keine Verbindung zu Dritten hergestellt.

Wenn Sie eine Figur auswählen oder gestalten, speichert Ihr Browser die Auswahl (Figur, Frisur, Farben, Begleiter ein oder aus) im lokalen Speicher Ihres Geräts, damit sie beim nächsten Besuch erhalten bleibt. Diese Angaben werden nicht an uns übertragen. Sie können sie jederzeit löschen, indem Sie die Websitedaten in Ihrem Browser entfernen.

Externe Links

Externe Projekt- und Profilseiten werden erst aufgerufen, wenn Sie den jeweiligen Link öffnen. Für die Verarbeitung auf diesen Websites sind deren Betreiber verantwortlich.

YouTube-Trailer

Der iQuest-Trailer wird über YouTube bereitgestellt. Vor dem Start zeigt die Website ein lokal gespeichertes Projektbild; es wird noch keine Verbindung zu YouTube hergestellt. Erst wenn Sie auf den Trailer klicken, wird der Player über www.youtube-nocookie.com geladen. Dabei werden insbesondere Ihre IP-Adresse und technische Browserinformationen an YouTube beziehungsweise Google übermittelt. Auch im erweiterten Datenschutzmodus können nach dem Start weitere Daten verarbeitet werden.

Alternativ können Sie den Trailer über den angebotenen Link direkt auf YouTube öffnen. Weitere Informationen finden Sie in der Datenschutzerklärung von Google.

Digitale Unterschriftslinks

Über einen persönlichen Link können Sie Kim Betcher eine handschriftlich eingegebene Unterschrift als PNG-Datei übermitteln. Auf der Seite sehen Sie den zugeordneten Namen, den Vorgang und die Empfängeradresse, bevor Sie den Versand bestätigen. Verarbeitet werden Name, Vorgangsangabe, Unterschriftsbild sowie Erfassungs- und Versandzeitpunkt und eine Prüfsumme. Die Daten dienen der Zuordnung und Bearbeitung dieses Vorgangs.

Die technische Verarbeitung erfolgt über Cloudflare Workers und D1; der E-Mail-Versand erfolgt über Resend an kim.betcher@schwaebisch-hall.de. Nach Annahme des Versands durch den Maildienst wird das Unterschriftsbild auf dem Server gelöscht. Bei einem Versandfehler bleibt es für einen erneuten Versuch vorübergehend gespeichert und wird spätestens nach 24 Stunden automatisch gelöscht. Name, Vorgangsangabe, Zeitpunkte und Prüfsumme bleiben zur Nachverfolgung erhalten. Die versandte E-Mail mit Anhang wird im Empfängerpostfach für die Bearbeitung des Vorgangs aufbewahrt. Der persönliche Link gilt sieben Tage und kann vor Verwendung gesperrt werden.
